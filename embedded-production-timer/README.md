# Embedded Production Timer System

## Overview
Custom embedded production timer system designed for manufacturing environments requiring configurable timing logic, visual status indication, and compact operator interaction.

## Contributions
- Designed custom PCB layout and hardware architecture
- Integrated LCD display and tactile user interface
- Developed enclosure and mechanical packaging concepts
- Worked through board-level electrical routing and manufacturing considerations
- Iterated physical layout for manufacturability and usability

## Technologies & Tools
- KiCad
- Embedded electronics
- PCB layout
- CAD modeling
- Additive manufacturing
- Rapid prototyping
